# 🔑 안전 탐험대 방탈출 (초등)

현장체험학습·수학여행 전에 하는 **사전 안전교육을 방탈출 게임으로 바꾼 초등학생용 웹사이트**입니다.
설치 없이 브라우저에서 바로 실행되며, 태블릿·크롬북·휴대폰·전자칠판에서 모두 사용할 수 있습니다.

## 구성

| 방 | 주제 | 열쇠 글자 |
|---|---|---|
| 1. 🎒 출발 준비실 | 준비물, 건강 상태 알리기, 이름표와 개인정보 | 안 |
| 2. 🚌 흔들흔들 버스 | 안전벨트, 차내 행동, 하차 후 길 건너기 | 전 |
| 3. 🛣️ 잠깐! 휴게소 | 출발 시간·버스 번호 기억, 주차장 안전, 버스를 놓쳤을 때 | 한 |
| 4. 🎡 북적북적 체험장 | 모둠 행동, 길을 잃었을 때, 낯선 사람 | 체 |
| 5. 🍱 점심과 물가 | 손 씻기, 식품 알레르기, 물놀이 안전 | 험 |
| 6. 🛏️ 숙소 생활 | 방·욕실 안전, 방문 노크 대처, 밤 외출 금지 | 학 |
| 7. 🏨 숙소의 밤: 비상 대피 | 비상구 확인, 화재 대피, 지진 대피 | 습 |
| 8. 🚑 응급 구조실 | 친구가 다쳤을 때, 코피, 119·112 | 비밀번호 `안전한체험학습` |

- 문제 유형: O/X, 고르기, 모두 고르기, 순서대로 누르기, **그림에서 찾기**(그림 속 친구를 눌러 ⭕ 안전 / ❌ 위험 판단, 8장면)
- 틀리면 힌트를 보고 다시 도전하고, 맞히면 해설이 나옵니다. 오답 수에 따라 방마다 별 1~3개
- 마지막에 **수료증(이름·안전 다짐·날짜)** 을 인쇄할 수 있습니다.
- 아래쪽 **📋 안전 수칙 모아보기**는 복습·게시용 인쇄 자료로 쓸 수 있습니다.
- 진행 상황은 각 기기 브라우저에 저장되며, **↺ 처음부터 다시**로 초기화합니다(다음 반 수업 전에 눌러 주세요).

## 수업 활용 예 (40분)

1. 도입(5분): 체험학습 장소·일정 안내, 모둠 이름 정하기
2. 방탈출(30분): 모둠별 1대 기기로 1~8번 방 진행
3. 정리(5분): 안전 수칙 모아보기 함께 읽기 → 수료증 다짐에 체크, 인쇄해 게시

## 그림 바꾸기

그림은 `img/` 폴더에 있습니다(bus, busstop, reststop, park, picnic, valley, room, hostel). 같은 이름으로 바꿔 넣으면 되고, 인물 위치가 달라지면 `js/data.js`의 `spots` 좌표(x·y·w·h, 그림 크기 대비 %)를 함께 고칩니다.

## 실행·배포

- 내 컴퓨터: `index.html`을 더블클릭
- 온라인 배포: Vercel에서 이 저장소를 Import(Framework Preset: Other, 빌드 설정 없음)하면 `main` 브랜치가 자동 배포됩니다.

## 문제 수정하기

문제와 안전 수칙은 모두 `js/data.js`에 있습니다. 학교 일정(물놀이가 없는 경우, 당일 체험학습 등)에 맞게 문장을 고치거나 문제를 바꿀 수 있습니다.
